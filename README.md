# DogMuzzle — визуализация инференса намордников

Приложение построено на Expo Router и даёт оператору веб-интерфейс, который умеет:

- принимать изображения и видео;
- отправлять их на REST API с моделью детекции собак в наморднике;
- поверх предпросмотра рисовать bounding boxes, отображать confidence score и служебные поля (frame/id);
- показывать справку по интеграции прямо в приложении.

## Быстрый старт

```bash
npm install
npx expo start --web
```

По умолчанию изображения улетают на `http://localhost:8000/detect/image`, а видео — на `http://localhost:8000/detect/video`. Поменяйте адрес через переменную окружения:

```bash
EXPO_PUBLIC_API_URL="https://dogmuzzle.server/api" npx expo start --web
```

Чтобы работать без реального бэкенда, включите мок-режим:

```bash
EXPO_PUBLIC_USE_MOCK=true npx expo start --web
```

## Формат API

REST-интерфейс FastAPI состоит из двух основных частей:

1. `POST /detect/image` — принимает FormData с полем `image` и возвращает JSON с массивом `detections` и абсолютными координатами (в пикселях).
2. `POST /detect/video` — принимает `video` и отдаёт размеченный mp4 (прямоугольники уже нанесены на каждый кадр).

Пример ответа `/detect/image`:

```json
{
  "label": "muzzle",
  "confidence": 0.92,
  "x_min": 120,
  "y_min": 80,
  "x_max": 340,
  "y_max": 280
}
```

Клиент определяет размер исходного изображения, нормализует координаты и рисует подписи поверх предпросмотра.

Пример запроса для изображения:

```bash
curl -X POST http://localhost:8000/detect/image \
  -F "image=@dog.jpg"

curl -X POST http://localhost:8000/detect/video \
  -F "video=@clip.mp4" \
  --output annotated_clip.mp4
```

## Структура UI

- Вкладка **Детектор** — основная форма загрузки, предпросмотр с bounding boxes и список детекций.
- Вкладка **Аналитика** — KPI, графики и фильтры по диапазону дат/источникам (данные тянутся из `/api/v1/stats/summary` и `/api/v1/history`). Диапазон ограничен 31 днём.
- Вкладка **История** — таблица запросов с фильтрами, пагинацией и просмотром деталей (в том числе raw JSON по запросу).
- Вкладка **Документация** — подсказки по формату запроса и переменным окружения.

Ключевые компоненты лежат в `components/detector`, работа с сетью — в `lib/api.ts`, типы структур собраны в `types/detection.ts`.

## Новые API для аналитики

Интерфейс ожидает, что REST-сервис отдаёт историю и агрегаты по маршрутам:

- `GET /api/v1/history?limit=&offset=&from=&to=&status=&source_type=` — пагинированный список запросов, который отображается во вкладке «История» и используется для построения таймсерий.
- `GET /api/v1/history/{request_id}?include_raw=` — детали запроса и, при необходимости, сырой JSON от модели.
- `GET /api/v1/stats/summary?from=&to=&source_type=` — агрегированные KPI за период, которые показаны на карточках во вкладке «Аналитика».

Для графиков фронт подтягивает историю батчами по 100 записей (до 5000 строк) и группирует их по дням. Если диапазон больше 31 дня, пользователю предлагается его сузить.
